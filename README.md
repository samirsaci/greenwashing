# Greenwashing Detection with Change Point Analysis 🌿
*Use the ruptures library to find the moment a sustainability claim stops matching the data*

The notebook runs change point detection with the ruptures library on a CO2 emissions series (`co2_emissions.csv`), so a claim of continuous improvement can be checked against the dates where the series actually changed regime.
